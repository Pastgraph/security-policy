# Pastgraph Security Policy

Report security issues privately:

https://github.com/Pastgraph/security-policy/security/advisories/new

Neither the publication of this policy nor the presence of a `security.txt`
file on any Pastgraph-owned host permits security testing, scanning, fuzzing,
or other unauthorised access. No testing of Pastgraph systems is permitted.
We still welcome reports of vulnerabilities discovered without such testing
(for example accidental findings).

Please consider that Pastgraph is used by real families. Prefer reports that
avoid unnecessary access to personal or family data, and describe impact
with care.
